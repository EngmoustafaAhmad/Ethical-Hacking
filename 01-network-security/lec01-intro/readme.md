# 🔐 Information & Network Security Concepts

## 📘 Overview

This section covers the fundamental concepts of **Cybersecurity**, including security objectives, types of attacks, cryptographic mechanisms, and network protection strategies. It provides the theoretical foundation required for ethical hacking and defensive security practices.

---

## 🔐 1. Cybersecurity

Cybersecurity is the collection of:

* Tools
* Policies
* Technologies
* Practices

### 🎯 الهدف:

Protect:

* Devices
* Networks
* Applications
* Data
* Users

---

## 🎯 2. Security Objectives (CIA Triad)

### 🔒 Confidentiality

Ensures that sensitive data is not disclosed to unauthorized users.

* Data Confidentiality
* Privacy

---

### 🧾 Integrity

Ensures that data is not altered without authorization.

* Data Integrity
* Authenticity
* Nonrepudiation

---

### ⚡ Availability

Ensures systems remain accessible and operational.

* No service interruption
* Reliable system performance

---

## 🧠 3. Key Differences

| Concept              | Description                    |
| -------------------- | ------------------------------ |
| Information Security | Protects data                  |
| Network Security     | Protects networks and services |

---

## ⚠️ 4. Threat vs Attack

### 🔸 Threat

A potential danger that could exploit a vulnerability.

### 🔸 Attack

An actual attempt to break security.

---

## 🧨 5. Types of Security Attacks

### 🟢 Passive Attacks

* Eavesdropping
* Traffic Analysis

✔️ Goal: Collect information
❌ No system modification

---

### 🔴 Active Attacks

* Masquerade (Impersonation)
* Replay Attack
* Data Modification
* Denial of Service (DoS)

✔️ Goal: Alter or disrupt system

---

## 🧩 6. OSI Security Architecture

* **Security Attack** → Action that compromises security
* **Security Mechanism** → Tool to prevent/detect attacks
* **Security Service** → Enhances system security

---

## 🔑 7. Security Services

* Authentication
* Access Control
* Data Confidentiality
* Data Integrity
* Nonrepudiation
* Availability

---

## 🔐 8. Cryptographic Mechanisms

### 🔸 Hash Functions

Convert data into fixed-length values.

### 🔸 Symmetric Encryption

* Uses one secret key

### 🔸 Asymmetric Encryption

* Uses public and private keys

### 🔸 Digital Signature

* Verifies identity and integrity

---

## 🌐 9. Network Security Areas

### 📡 Communications Security

* Protects data during transmission
* Uses secure protocols

### 💻 Device Security

* Firewall
* IDS (Intrusion Detection System)
* IPS (Intrusion Prevention System)

---

## 🧱 10. Security Challenges

* Security is complex
* Continuous monitoring required
* Attacks are constantly evolving
* May affect performance
* Ongoing battle between attacker and defender ⚔️

---

## 🌍 11. Standard Organizations

* **NIST** → Security standards
* **ISO** → International standards
* **ITU-T** → Telecom standards
* **IETF / ISOC** → Internet standards

---

## 🔥 12. Attack vs Defense

| Attack            | Defense                    |
| ----------------- | -------------------------- |
| Sniffing          | Encryption (TLS)           |
| DoS               | Firewall + Rate Limiting   |
| Masquerade        | Authentication             |
| Data Modification | Hashing & Integrity Checks |
