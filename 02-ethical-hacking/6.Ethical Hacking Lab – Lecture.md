# 1. Web Server Concepts

## What is a Web Server?

A web server is a system that stores, processes, and delivers web pages to users through HTTP or HTTPS protocols.

### Main Functions
- Host websites
- Handle client requests
- Deliver web pages and files
- Process dynamic content

---

## Common Web Servers

| Web Server | Description |
|---|---|
| Apache | Open-source and widely used |
| Nginx | High-performance web server |
| IIS | Microsoft web server |
| LiteSpeed | Optimized commercial server |

---

## How Web Servers Work

### Basic Flow

1. User enters a URL in browser
2. Browser sends HTTP request
3. Web server processes request
4. Server returns response
5. Browser displays webpage

---

## HTTP vs HTTPS

| Feature | HTTP | HTTPS |
|---|---|---|
| Security | Not encrypted | Encrypted |
| Port | 80 | 443 |
| Protection | No | SSL/TLS protection |

# 2. Web Server Attacks

Web servers are common attack targets because they are exposed to the internet.

---

## A) Directory Traversal Attack

### Concept
Attackers try to access files outside the web root directory.

### Example
```bash
../../etc/passwd
```

Risks
Access sensitive files
Reveal configurations
Leak credentials

## B) SQL Injection (SQLi)
Concept

Inject malicious SQL queries into input fields.

```Example
' OR '1'='1
```
Risks
Database compromise
Data theft
Authentication bypass

## C) Cross-Site Scripting (XSS)
Concept

Inject malicious JavaScript into webpages.

Types
Stored XSS
Reflected XSS
DOM-based XSS
Risks
Session hijacking
Cookie theft
Fake pages

## D) File Upload Attacks
Concept

Upload malicious files to the server.

Risks
Remote code execution
Malware hosting
Server takeover

## E) Denial of Service (DoS)
Concept

Flood server with excessive requests.

Risks
Server crash
Service unavailability

## F) Brute Force Attack
Concept

Try many username/password combinations.

Risks
Unauthorized access
Account compromise

## G) Misconfiguration Exploitation
Examples
Default credentials
Open admin panels
Directory listing enabled
Risks
Sensitive information exposure
Easy server compromise

# 3. Web Server Attack Countermeasures

## A) Keep Software Updated
Patch vulnerabilities
Update web server software
Update plugins and frameworks

## B) Use Strong Authentication
Strong passwords
Multi-factor authentication (MFA)
Account lockout policies

## C) Configure Proper Permissions
Restrict file access
Disable unnecessary services
Apply least privilege principle

## D) Use HTTPS
Benefits
Encrypt communication
Prevent packet sniffing
Protect credentials

## E) Input Validation
Prevents
SQL Injection
XSS attacks
Command injection

## F) Web Application Firewall (WAF)
Purpose

Filter malicious traffic before reaching the server.

## G) Disable Directory Listing
Prevents

Attackers from viewing server files and folders.

## H) Monitor Logs
Helps Detect
Suspicious activity
Failed logins
Attack attempts

# 4. Patch Management
What is Patch Management?

Patch management is the process of updating systems and software to fix vulnerabilities and improve security.

Importance of Patch Management
Benefits
Fix security vulnerabilities
Improve stability
Reduce attack surface
Protect against exploits
Patch Management Process
## 1. Identify Vulnerabilities

Find outdated software and weaknesses.

## 2. Test Patches

Verify updates before deployment.

## 3. Deploy Updates

Install patches on systems.

## 4. Verify Installation

Ensure updates work correctly.

## 5. Monitor Systems

Check for issues after patching.

Risks of Poor Patch Management
Exploitation of known vulnerabilities
Malware infections
Data breaches
System compromise
Best Practices
Regularly update systems
Use automatic updates when possible
Backup systems before patching
Monitor security advisories
Remove unused software
